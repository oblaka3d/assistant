# 📋 План реализации проекта голосового ассистента для BTT Pi 1.2

Этот документ содержит детальный план реализации голосового ассистента на базе BTT Pi 1.2 с использованием закупленных комплектующих.

> 📦 **Эпики проекта!** Для структурированного списка задач в формате эпиков см.: **[EPICS.md](./EPICS.md)**  
> 🎨 **Техническое задание для дизайнера!** Если вы работаете с дизайнером UI/UX, используйте: **[DESIGN_SPECIFICATION.md](../design/DESIGN_SPECIFICATION.md)**

---

## 📦 Комплектующие из заказа

### Основное оборудование:

- ✅ **BTT Pi 1.2** - одноплатный компьютер (ARM64)
- ✅ **Динамик** (колонка) - для воспроизведения речи
- ✅ **Камеры** (2M HD Camera + Super wide angle lens) - опционально для видеовизуализации
- ✅ **Микрофон** - для записи голоса (возможно в составе USB-аудио карты)
- ✅ **Платы** (макетные платы) - для подключения компонентов
- ✅ **Антенны** - для Wi-Fi/Bluetooth
- ✅ **Батареи 18650** - для автономного питания (опционально)
- ✅ **Кабели и шлейфы** - для подключения компонентов

---

## 🎯 Общая концепция проекта

**Цель**: Создать автономный голосовой ассистент с 3D визуализацией персонажа на BTT Pi 1.2.

**Составляющие**:

1. **Hardware** - BTT Pi 1.2 + аудио + дисплей (опционально)
2. **OS** - Linux (Armbian/Debian/Ubuntu) на ARM64
3. **Software** - Electron приложение + Three.js 3D персонаж
4. **Audio** - ALSA для записи/воспроизведения
5. **AI** - STT + LLM + TTS через API

## 📅 Этапы реализации

### Этап 1: Подготовка оборудования (3-5 дней)

#### 1.1 Подготовка BTT Pi 1.2

- [ ] Проверить комплектацию BTT Pi 1.2
- [ ] Подключить SD-карту (рекомендуется 32GB+, класс 10+)
- [ ] Подключить питание (5V, минимум 2A)
- [ ] Подключить дисплей (HDMI или eDP, если нужен)
- [ ] Проверить индикаторы питания/статуса

#### 1.2 Подготовка аудио компонентов

- [ ] Подключить USB-аудио карту с микрофоном (если нет встроенного)
- [ ] Подключить динамик через 3.5mm или USB
- [ ] Проверить работу микрофона: `arecord -l`
- [ ] Проверить работу динамика: `aplay -l`
- [ ] Настроить уровни громкости через `alsamixer`

#### 1.3 Подключение антенн (если требуется)

- [ ] Установить Wi-Fi антенну
- [ ] Проверить подключение к сети: `iwconfig` / `nmcli`
- [ ] Настроить статический IP (опционально)

#### 1.4 Подключение дисплея (опционально)

- [ ] Подключить HDMI дисплей или сенсорный экран
- [ ] Настроить разрешение экрана
- [ ] Проверить отображение через X11/Wayland

**Результат этапа**: Работающее железо с базовой конфигурацией.

### Этап 2: Установка и настройка ОС (2-3 дня)

#### 2.1 Установка операционной системы

- [ ] Скачать образ ОС для BTT Pi 1.2 (Armbian/Debian/Ubuntu)
  - Рекомендуется: **Armbian** или **Debian Bullseye**
  - Проверить совместимость с ARM64
- [ ] Записать образ на SD-карту через:

  ```bash
  # Linux/Mac
  dd if=image.img of=/dev/sdX bs=4M status=progress

  # Windows
  # Использовать balenaEtcher или Win32DiskImager
  ```

- [ ] Вставить SD-карту в BTT Pi 1.2
- [ ] Первый запуск и базовая настройка

#### 2.2 Первичная настройка системы

- [ ] Подключение по SSH (если нет дисплея):
  ```bash
  ssh root@btt-pi-ip
  # или
  ssh pi@btt-pi-ip  # если создан пользователь pi
  ```
- [ ] Обновление системы:
  ```bash
  sudo apt update
  sudo apt upgrade -y
  ```
- [ ] Установка базовых утилит:
  ```bash
  sudo apt install -y vim git curl wget build-essential
  ```

#### 2.3 Настройка пользователя и прав

- [ ] Создать пользователя (если не создан):
  ```bash
  sudo adduser pi
  sudo usermod -aG sudo pi
  ```
- [ ] Добавить пользователя в группу audio:
  ```bash
  sudo usermod -a -G audio pi
  ```
- [ ] Настроить автологин (если нужен дисплей):
  ```bash
  # Для systemd
  sudo systemctl set-default graphical.target
  ```

**Результат этапа**: Работающая ОС с настроенным пользователем.

### Этап 3: Настройка аудио системы (1-2 дня)

#### 3.1 Установка ALSA утилит

- [ ] Установка ALSA:
  ```bash
  sudo apt install -y alsa-utils alsa-base
  sudo apt install -y pulseaudio pulseaudio-utils
  ```
- [ ] Проверка аудио устройств:

  ```bash
  # Список карт
  aplay -l
  arecord -l

  # Детальная информация
  cat /proc/asound/cards
  ```

#### 3.2 Настройка микрофона

- [ ] Определить устройство микрофона:
  ```bash
  arecord -l  # показать список устройств
  ```
- [ ] Проверить работу микрофона:

  ```bash
  # Запись тестового файла (5 секунд)
  arecord -d 5 -f cd test.wav

  # Воспроизведение
  aplay test.wav
  ```

- [ ] Настроить устройство по умолчанию:

  ```bash
  # Создать файл ~/.asoundrc
  cat > ~/.asoundrc << EOF
  pcm.!default {
      type hw
      card 0
      device 0
  }

  ctl.!default {
      type hw
      card 0
  }
  EOF
  ```

- [ ] Настроить уровень записи:
  ```bash
  alsamixer
  # Найти Capture и повысить уровень до 70-80%
  ```

#### 3.3 Настройка динамика/колонки

- [ ] Определить устройство воспроизведения:
  ```bash
  aplay -l
  ```
- [ ] Проверить воспроизведение:

  ```bash
  # Тестовый звук
  speaker-test -t wav -c 2

  # Воспроизведение файла
  aplay /usr/share/sounds/alsa/Front_Left.wav
  ```

- [ ] Настроить уровень громкости:
  ```bash
  alsamixer
  # Настроить Master и PCM уровни
  ```

#### 3.4 Настройка прав доступа

- [ ] Создать udev правила (если нужно):

  ```bash
  sudo tee /etc/udev/rules.d/99-microphone.rules > /dev/null << EOF
  SUBSYSTEM=="sound", KERNEL=="card*", MODE="0666"
  EOF

  sudo udevadm control --reload-rules
  ```

**Результат этапа**: Работающий микрофон и динамик с правильными настройками.

### Этап 5: Настройка API ключей (1 день)

#### 5.1 Получение API ключей

- [ ] **STT (Speech-to-Text)**:
  - OpenAI Whisper API
    - Регистрация: https://platform.openai.com/signup
    - Получение API ключа
  - ИЛИ Yandex SpeechKit
    - Регистрация: https://cloud.yandex.ru/
    - Получение API ключа и Folder ID

- [ ] **LLM (Language Model)**:
  - OpenAI GPT API
    - Использовать тот же ключ, что для STT
    - Или получить отдельный
  - ИЛИ YandexGPT
    - Использовать ключ из Yandex Cloud
  - ИЛИ DeepSeek API
    - Регистрация: https://platform.deepseek.com/

- [ ] **TTS (Text-to-Speech)**:
  - Yandex TTS API
    - Использовать ключ из Yandex Cloud
  - ИЛИ Silero TTS (локальный, не требует API)
  - ИЛИ OpenAI TTS

#### 5.2 Настройка переменных окружения

- [ ] Создать файл `.env`:
  ```bash
  cp .env.example .env
  nano .env
  ```
- [ ] Заполнить API ключи:

  ```env
  # STT API
  STT_API_URL=https://api.openai.com/v1/audio/transcriptions
  STT_API_KEY=your_stt_api_key_here

  # LLM API
  LLM_API_URL=https://api.openai.com/v1/chat/completions
  LLM_API_KEY=your_llm_api_key_here
  LLM_MODEL=gpt-3.5-turbo

  # TTS API
  TTS_API_URL=https://tts.api.cloud.yandex.net/speech/v1/tts:synthesize
  TTS_API_KEY=your_tts_api_key_here
  TTS_VOICE=jane
  ```

- [ ] Установить права доступа:
  ```bash
  chmod 600 .env
  ```

**Результат этапа**: Настроенные API ключи для работы ассистента.

### Этап 8: Настройка автозапуска (1 день)

#### 8.1 Создание systemd сервиса

- [ ] Создать файл сервиса:
  ```bash
  sudo nano /etc/systemd/system/voice-assistant.service
  ```
- [ ] Добавить конфигурацию:

  ```ini
  [Unit]
  Description=Voice Assistant ARM
  After=network.target sound.target graphical.target
  Wants=graphical.target

  [Service]
  Type=simple
  User=pi
  WorkingDirectory=/home/pi/voice-assistant-arm
  Environment="DISPLAY=:0"
  Environment="XAUTHORITY=/home/pi/.Xauthority"
  Environment="NODE_ENV=production"
  ExecStart=/usr/bin/npm run start
  Restart=always
  RestartSec=10
  StandardOutput=journal
  StandardError=journal

  [Install]
  WantedBy=multi-user.target
  ```

#### 8.2 Активация сервиса

- [ ] Перезагрузить systemd:
  ```bash
  sudo systemctl daemon-reload
  ```
- [ ] Включить автозапуск:
  ```bash
  sudo systemctl enable voice-assistant.service
  ```
- [ ] Запустить сервис:
  ```bash
  sudo systemctl start voice-assistant.service
  ```
- [ ] Проверить статус:
  ```bash
  sudo systemctl status voice-assistant.service
  ```

#### 8.3 Настройка автологина (если нужен дисплей)

- [ ] Для Armbian/Debian:

## ⚠️ Важные замечания

### Производительность BTT Pi 1.2

- BTT Pi 1.2 имеет ограниченную производительность
- 3D сцена Three.js должна быть оптимизирована:
  - Низкополигональные модели
  - Простые шейдеры
  - Низкое разрешение рендеринга (720p или ниже)

### Питание

- Требуется стабильное питание 5V, минимум 2A
- Использовать качественный блок питания
- При использовании батарей - контроллер заряда обязателен

### Сеть

- Для работы API требуется стабильное интернет-соединение
- Рекомендуется проводное подключение (если возможно)
- Или надежный Wi-Fi

### Температура

- Следить за температурой процессора
- При необходимости добавить радиатор/охлаждение
- Проверять температуру: `vcgencmd measure_temp` (если доступно)

Перед первым запуском проверьте:

- [ ] BTT Pi 1.2 включен и загружается
- [ ] ОС установлена и работает
- [ ] Микрофон подключен и определяется системой
- [ ] Динамик подключен и работает
- [ ] Сеть настроена и есть интернет
- [ ] Node.js установлен и работает
- [ ] Проект склонирован и зависимости установлены
- [ ] API ключи настроены в `.env`
- [ ] 3D модель скопирована в `apps/desktop/public/assets/models/`
- [ ] Приложение собирается без ошибок: `npm run build`
- [ ] Тестовый запуск прошел успешно: `npm run start:window --workspace @assistant/desktop`
