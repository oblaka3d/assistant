# 🎨 Design specification (UI/UX)

Этот документ нужен, чтобы **согласовать дизайн** (структуру экранов, компоненты, состояния, размеры, палитры) и не держать требования “в голове”.

## Контекст продукта

- **Платформа**: Electron (desktop), сенсорный сценарий (kiosk/window mode).
- **Навигация**: свайпы `main ↔ chat ↔ menu` + подэкраны в меню.
- **Темы**: `light` / `dark` / `system`, настраиваемые акцентные цвета.

## Экраны

- **WelcomeScreen**
  - Цель: первичное объяснение/старт.
  - Состояния: light/dark.
- **MainScreen**
  - Цель: 3D-персонаж + голосовое управление.
  - Состояния: idle/listening/thinking/talking.
- **ChatScreen**
  - Цель: текстовый чат + виртуальная клавиатура + emoji.
  - Состояния: welcome/диалог/панель диалогов/клавиатура.
- **MenuScreen**
  - Подэкраны: settings, apiKeys, applications, logs, about, auth.

## Компоненты (высокий уровень)

- Типографика: базовый набор (заголовки/текст/лейблы).
- Кнопки: primary/secondary/ghost + состояния disabled/loading.
- Поля ввода: text/password/search.
- Списки: диалоги, приложения.
- Диалоги: create/import/edit приложения.

## Анимации и микро-взаимодействия

- Переходы свайпом между экранами.
- Открытие/закрытие клавиатуры (смещение контента по `--keyboard-offset`).
