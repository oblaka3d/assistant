# 🎬 Unity Technical Specification (анимации/экспорт)

Этот документ — ТЗ для аниматора/Unity-инженера: какие анимации и состояния нужны, как экспортировать, какие ограничения учитывать.

## Состояния персонажа

- `idle`
- `listening`
- `thinking`
- `talking`

## Требования к анимациям

- Петли: `idle/listening/thinking/talking` должны быть loop-safe.
- Переходы: без резких рывков, допускается cross-fade.
- Скорость: управляемая параметром (при необходимости).

## Экспорт

- Формат: **GLB/GLTF** (если используется three.js pipeline) или WebGL build (если Unity реально рендерит в UI).
- Имена клипов: стабильные (см. состояния выше).

## Ограничения производительности

- Сенсорный “киоск” сценарий: важна стабильность FPS.
- Желательно: low-poly, простой шейдинг (toon — опционально).
