# 🧩 Unity Setup Guide (WebGL персонаж)

Этот документ описывает **минимальный рабочий процесс** для сборки WebGL-персонажа и его подключения к UI.

## Цель

- Получить WebGL build (папка `Build/`), который можно доставить в проект и загрузить в UI.

## Требования

- Unity Editor (версия согласуется командой; ориентир: LTS).
- WebGL Build Support установлен.

## Структура артефактов

Ожидаемая структура (пример):

```
unity/Build/
  index.html
  build.loader.js
  build.framework.js
  build.data
  build.wasm
```

## Сборка (черновой чеклист)

1. Открыть Unity проект.
2. Проверить настройки сцены/камеры/освещения.
3. `File → Build Settings → WebGL → Build`.
4. Положить результат в `unity/Build/`.
