# 🧩 Three.js Setup Guide (3D Character)

Этот документ описывает рабочий процесс для подготовки 3D модели персонажа и его интеграции в приложение на Three.js.

## Цель

- Подготовить оптимизированную 3D модель (GLB/GLTF) с анимациями.
- Разместить модель в ресурсах приложения для загрузки через Three.js.

## Требования

- 3D редактор (Blender, Maya, etc.).
- Экспорт в формат glTF 2.0 (.glb или .gltf + .bin).

## Структура ресурсов

Ожидаемое расположение модели в проекте:

```
apps/desktop/public/assets/models/
  character.glb
```

## Подготовка модели (Checklist)

1. **Формат**: Использовать binary glTF (.glb) для компактности.
2. **Анимации**: Все анимации должны быть запечены (baked) в файл модели или экспортированы как отдельные действия.
3. **Оптимизация**:
   - Минимизировать draw calls (объединять меши с одинаковыми материалами).
   - Использовать сжатые текстуры (при необходимости).
   - Следить за количеством полигонов (Low-poly/Mid-poly).
4. **Draco Compression**: Если файл слишком большой, можно использовать Draco сжатие (потребуется настроить `DRACOLoader` в Three.js).

## Интеграция с приложением

Модель загружается компонентом Three.js сцены в React приложении.
Основной путь: `apps/desktop/src/components/ThreeScene/` (или аналогичный, проверить актуальную структуру).

При обновлении модели:
1. Замените файл `character.glb` в `public/assets/models/`.
2. Проверьте имена анимаций в коде (они должны совпадать с именами в GLB файле).
